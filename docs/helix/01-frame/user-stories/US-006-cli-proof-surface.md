# User Story: US-006 — Exercise the Public Service from a CLI

**Status**: Approved
**Feature**: FEAT-006
**Feature Requirements**: thin command and machine-readable harness adapter
**PRD Requirements**: FR-6

As an operator or harness integrator, I want to invoke and inspect the public
Fizeau service from `fiz`, so that I can prove or automate the library contract
without adopting a second runtime.

## Acceptance Criteria

- **US-006-AC1** — **Given** a CLI execution against a configured provider,
  **when** the invocation succeeds, **then** JSON output preserves the public
  final result and carries the `svc-` session identity generated by
  `FizeauService.Execute`.
- **US-006-AC2** — **Given** a machine-readable invocation, **when** progress
  and final output are emitted, **then** they remain separable and the final
  output preserves public result semantics.
- **US-006-AC3** — **Given** the standalone process wiring, **when** its source
  boundary is checked, **then** `cmd/fiz/main.go` neither imports
  `internal/core` nor calls the core loop directly.
