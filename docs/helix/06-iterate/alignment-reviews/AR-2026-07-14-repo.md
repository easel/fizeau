## Intent Summary

- **Vision**: Fizeau is an embeddable Go runtime whose owned agent loop makes
  work measurable and gives local models the same product surface as cloud
  models. The library is the product; `fiz` is its proof CLI.
- **Requirements**: Eight canonical subsystems now define embedded execution,
  workspace tools, provider parity, routing/catalog, measurement/replay, the
  CLI proof surface, distribution, and benchmark evidence.
- **Features / Stories**: Every subsystem maps to one approved feature and one
  approved top-level story. The 21 stable story criteria describe observable
  public behavior rather than private implementation names.
- **Architecture / ADRs**: The root `fizeau` package is the public facade;
  concrete execution belongs under `internal/`. Fizeau owns one selected route
  and its evidence; the caller owns semantic retry and cross-harness
  escalation. All 17 ADR records have an explicit accepted status.
- **Technical Design**: Current package ownership is documented. Historical
  loop, rename, and catalog plans are marked as implementation reference rather
  than current public architecture.
- **Test Plans**: TP-001 records exact story-to-test citations and treats a
  citation without a relevant assertion as `ASSERTED_UNBACKED`. Coverage
  measurement now fails closed on test failure or zero parsed packages.
- **Implementation Plans**: The durable build plan defines gates and sizing;
  the DDx queue remains the only live backlog.

## Implementation Map

- **Topology**: root `fizeau` facade; `internal/serviceimpl` dispatch;
  `internal/core` native loop; `internal/provider` native providers;
  `internal/harnesses` subprocess adapters; service-owned transcript,
  route-health, quota, routing-quality, session, and cache packages.
- **Entry Points**: `fizeau.New(...).Execute` and related public projections;
  `agentcli.MountCLI` for embedding; `cmd/fiz` for standalone process wiring.
- **Test Surfaces**: root external-contract tests, owning-package unit tests,
  harness cassettes, isolated CLI subprocess tests, shell installer acceptance,
  and browser workbench smoke tests.
- **Plugin Runtime**: user-scoped marketplace installs provide HELIX 0.10.2
  and the Claude DDx plugin 1.0.0; the installed DDx CLI reports
  `v0.6.2-alpha104-17952-g8eb3a46f7`. Repository-local plugin copies are no
  longer a second source of truth.
- **Document Graph**: `.ddx/graphs/helix.yaml` restricts DDx discovery to the
  canonical `docs/helix` stack; benchmark verify-worktree copies remain
  evidence only.
- **Unplanned Areas**: no unplanned runtime area was promoted to authority by
  this review. The telemetry classification, public final cost-source, and
  progress token-shape gaps are called out explicitly rather than hidden
  behind a coverage claim.
