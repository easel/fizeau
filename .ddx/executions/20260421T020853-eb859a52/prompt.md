    <title>harness-pty: build direct PTY probe substrate</title>
    <description>
Build the narrow direct PTY substrate selected by ADR-002 and ADR-004 for short-lived background metadata probes and cassette evidence. The first production use is: start a harness briefly, drive the minimum TUI flow needed for quota/status/model/reasoning facts, capture rendered VT state and raw events for cassette/debug output, and exit cleanly. This is not a terminal manager and not a tmux wrapper. Normal prompt execution remains on harness-native batch modes unless a future design promotes PTY interactive execution as a fallback. In-scope package boundaries are internal/pty/session for process and PTY lifecycle, internal/pty/terminal for VT/ANSI byte-to-frame derivation and snapshots, and a narrow internal/pty/cassette-facing event stream consumed by follow-up cassette work. Packages below internal/pty must not import internal/harnesses or contain Claude/Codex quota, model, reasoning, or harness policy.
    </description>
    <acceptance>
1. The implementation cites ADR-002, ADR-004, SPIKE-001, SPIKE-002, and the harness-golden TUI-only checklist before introducing internal/pty code.&#xA;2. No tmux adapter, tmux shell-out, tmux import, tmux socket/session management, or tmux-backed capability path is introduced.&#xA;3. internal/pty/session exposes a narrow API for Start(command,args,workdir,env,size), SendBytes/SendKey, Resize, output streaming, Wait, Close, Kill, timeout, cancellation, process-group cleanup, and exit status.&#xA;4. internal/pty/terminal wraps a real VT/ANSI emulator backend behind an internal interface; regex ANSI stripping is not accepted as the screen model.&#xA;5. internal/pty/terminal exposes deterministic snapshots of current rendered VT state: screen text/cells, cursor metadata, terminal size, frame timestamp/seq, and enough raw-byte offset context to debug parser failures.&#xA;6. The substrate emits timed raw output chunks, timed input events, resize/signal events, and derived frame events in the shape needed by internal/pty/cassette, without owning cassette persistence in this bead.&#xA;7.
